# Property Management System

This project is a web-based property management system developed as my final thesis project.
The goal of the system is to support the digital management of residential communities
and improve communication between property management and residents.

## Project Background
This project was created as part of my university graduation project.
It focuses on a typical real-world application scenario and was designed
to practice full-stack development with a clear separation between frontend and backend.

## Technologies
### Backend
- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- MySQL

### Frontend
- Vue.js
- HTML / CSS / JavaScript

## Architecture
The system follows a classic frontend-backend separation and the MVC pattern:

- Frontend: handles user interaction and sends HTTP requests
- Backend: processes business logic and exposes RESTful APIs
- Database: stores application data and supports CRUD operations

## Core Features
- User management (basic user data handling)
- Property and community information management
- Backend REST API for data processing
- Database persistence with MySQL
- Frontend interface for basic interaction
